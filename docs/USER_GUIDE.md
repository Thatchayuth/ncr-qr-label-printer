# คู่มือใช้งาน NCR QR Label Printer

สำหรับ: ผู้ใช้งานที่พิมพ์สติกเกอร์ QR ติดทรัพย์สิน

## พิมพ์สติกเกอร์ (หน้า Search & Print)

1. ตรวจ**บริษัท**ที่ปุ่มมุมซ้ายล่าง (ใต้ AX LIVE) เช่น `DB1 · NCR Rubber DB1` ถ้าจะเปลี่ยน ให้คลิกที่ปุ่มแล้วเลือกจากรายการ
2. ใส่เงื่อนไขค้นหาช่องใดช่องหนึ่งหรือหลายช่องพร้อมกัน แล้วกด **Search** หรือกด Enter

   | พิมพ์ในช่อง | ผลที่ได้ |
   |---|---|
   | `FA-IT-5-26` | ทุกรายการที่มีข้อความนี้ |
   | `FA-IT-5-26-0001..FA-IT-5-26-0010` | เป็นช่วง (**ใส่เลขให้เต็ม**) |
   | `FA-IT-5-26-0001, FA-IT-5-26-0005` | เฉพาะเลขที่ระบุ |
   | copy ทั้งคอลัมน์จาก Excel มาวาง | ทุกเลขในรายการ (สูงสุด 200 เลข) |

   ถ้าต้องการกรองตามวันที่สร้าง ให้ติ๊ก **Filter from** ที่ Created date แล้วเลือกช่วงวันที่
3. **ติ๊กช่อง ☐ หน้าแถว**ที่จะพิมพ์ (แถวที่ติ๊กไว้จะมีพื้นสีเขียวอ่อน) คลิกช่องซ้ำเพื่อเอาติ๊กออก คลิกหัวคอลัมน์ ✓ หรือกด **Tick all** เพื่อติ๊กทั้งหมด ส่วนการ**คลิกที่แถว**จะแค่แสดงตัวอย่างฉลาก ไม่ติ๊ก ถ้าต้องการติ๊กแถวที่กำลังเลือกอยู่ให้กดปุ่ม **Space**
4. ตรวจภาพตัวอย่างฉลากทางขวา
5. ตั้ง **Copies per label** (จำนวนดวงต่อ 1 รายการ) แล้วกด **Print**

## ตรวจผลการพิมพ์ (หน้า Print History)

| สถานะ | ความหมาย | ต้องทำอะไร |
|---|---|---|
| SpoolerAccepted | Windows รับงานแล้ว | ดูว่าสติกเกอร์ออกมาจริง |
| ConfirmedPrinted | มีคนยืนยันแล้วว่าพิมพ์ออก | — |
| Failed | ไม่ได้พิมพ์ | ดูสาเหตุ แล้วพิมพ์ใหม่ |
| **UnknownDelivery** (แถวสีเหลือง) | ไม่แน่ใจว่าพิมพ์ออกหรือไม่ | **ไปดูที่เครื่องก่อน** แล้วกด Mark printed หรือ Mark not printed |
| Cancelled | ยกเลิกแล้ว | — |

**ปุ่มที่ใช้บ่อย**
- **Reprint...** พิมพ์ซ้ำ ต้องใส่เหตุผลทุกครั้ง ฉลากจะออกมาเหมือนครั้งแรกทุกจุด
- **Check queue** เช็กว่างานยังค้างอยู่ในคิวของ Windows หรือไม่ เช่น เครื่อง offline หรือกระดาษหมด
- **Cancel in queue** ยกเลิกงานที่ยังค้างอยู่ในคิว
- **Export CSV...** ส่งออกรายการเพื่อเปิดใน Excel

## ข้อควรรู้

- โปรแกรม **อ่านข้อมูล AX อย่างเดียว** ไม่ได้แก้ข้อมูลใน AX
- เปิดโปรแกรมได้ทีละ 1 หน้าต่าง
- กด Print แล้ว ระหว่างที่ระบบกำลังส่งงาน ปุ่มจะกดซ้ำไม่ได้ ป้องกันการพิมพ์ซ้ำโดยไม่ตั้งใจ
- หน้า **Application Settings** ต้องใช้รหัส Admin

## สำหรับผู้ดูแล: ออกแบบฉลาก (Label Designer)

- **การจัดวาง:** ลากเพื่อย้าย, ลากสี่เหลี่ยมที่มุมเพื่อปรับขนาด, ใช้ปุ่มลูกศรเพื่อขยับทีละนิด
- **Layers:** จัดลำดับชั้น ล็อก หรือเปลี่ยนชื่อชิ้นต่าง ๆ บนฉลาก
- **รูปภาพ/โลโก้:** กด **Image** (Alt+6) แล้วเลือกไฟล์ ระบบจะแปลงรูปเป็นขาวดำ ถ้าเป็นรูปถ่ายให้ติ๊ก **Dither**
- **เส้นไกด์:** ตอนลากชิ้นไปใกล้กึ่งกลางฉลาก หรือใกล้กึ่งกลางชิ้นอื่น จะมีเส้นสีชมพูขึ้นและดูดให้ตรงกลางพอดี
- **บันทึก:** กด **Save** (Ctrl+S) ทุกครั้งที่บันทึกจะได้เวอร์ชันใหม่ งานพิมพ์ใหม่จะใช้เวอร์ชันล่าสุด
- **คีย์ลัดทั้งหมด:** กด **F1**

## สำหรับผู้ดูแล: ดึงข้อมูลจากตารางอื่น (Data Profiles)

ต้องใช้รหัส Admin

1. ถ้าข้อมูลมาจากหลายตารางและ join ซับซ้อน ให้ DBA สร้าง **View** ที่รวมข้อมูลไว้ก่อน (View ใช้ได้เหมือนตารางทุกอย่าง)
2. Data Profiles → **New** → ตั้งชื่อ → **Browse...** แล้วพิมพ์ชื่อตารางหรือ View เพื่อค้นหา → เลือก
3. **Company column:** ถ้าตารางมี DATAAREAID ให้เลือกคอลัมน์นี้ ถ้าไม่มีให้เลือก "(no company filter)"
4. **Add fields...** → ติ๊กคอลัมน์ที่ต้องการ → แก้ **Header** (ชื่อที่แสดงบนหน้าจอ) เลือกได้ว่าคอลัมน์ไหนค้นหาได้ (Search) และคอลัมน์ไหนกรองช่วงวันที่ได้ (Date range)
5. ถ้าต้องการข้อมูลจากตารางอื่นเพิ่ม → **Related tables → Add...** → เลือกตาราง → ระบุคอลัมน์ที่ใช้เชื่อม เช่น `ASSETID=ASSETID, DATAAREAID=DATAAREAID`
6. **Run test query** → ตรวจข้อมูล 20 แถวแรก (คำสั่ง SQL ที่แสดงอยู่ใต้ตาราง ส่งให้ DBA ตรวจได้)
7. **Save** → ไปตั้งค่าที่ **QR Configuration** ว่าจะใส่อะไรใน QR → เลือกแบบฉลากเริ่มต้นได้ที่ช่อง Default label
8. หน้า Search & Print → เลือกโปรไฟล์ใหม่จากช่อง **Data profile**

> SQL login ที่โปรแกรมใช้ต้องมีสิทธิ์อ่านตารางหรือ View นั้นด้วย ถ้า Test แล้วขึ้น "The table or view does not exist, or the login cannot read it" ให้ขอ DBA เพิ่มสิทธิ์อ่าน
